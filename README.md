# Calculator Pro 3.0

واجهة حاسبة علمية وهندسية باللغة العربية، تشمل حل المعادلات، التفاضل والتكامل، رسم الدوال، وتحويل العملات والوحدات.

## الميزات

- محرك تعبيرات رياضية يتحقق من الإدخال قبل الحساب.
- حل المعادلات في المتغير `x`، والتفاضل والتكامل الرمزي.
- رسم الدوال باستخدام NumPy وMatplotlib.
- تحويل وحدات الطول والوزن والحرارة.
- أسعار صرف مرجعية من مزودي البيانات المضمّنين، مع إدخال أسعار يدويًا.
- حفظ الإعدادات وأسعار الصرف وسجل الأخطاء في مجلد بيانات المستخدم.
- واجهة تتكيف مع حجم النافذة، مع شروح سياقية للأزرار.

## التشغيل من المصدر

يتطلب Python 3.10 أو أحدث وبيئة سطح مكتب تدعم Tk.

```powershell
py -m pip install -r requirements.txt
py calculator_pro_v3.py
```

## إنشاء نسخة Windows

شغّل `build_exe.bat`. يضع ملف التشغيل ضمن `dist/CalculatorPro/`.

## بيانات العملات

الأسعار مرجعية وقد لا تطابق عروض البيع والشراء لدى البنوك أو مكاتب الصرافة. يحدّث التطبيق البيانات عبر الإنترنت عند طلب التحديث، ويمكن إدخال أسعار مخصصة. يعرض التطبيق عبارة الإسناد التي يطلبها ExchangeRate-API: “Rates By Exchange Rate API”.
