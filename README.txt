Calculator Pro 3.0
==================
التشغيل من الكود:
  1) ثبّت Python 3.10 أو أحدث (مع tkinter) من python.org
  2) pip install -r requirements.txt
  3) python calculator_pro_v3.py

صنع ملف exe للتوزيع: شغّل build_exe.bat (ينتج dist\CalculatorPro\CalculatorPro.exe).

بيانات المستخدم تُحفظ في: %APPDATA%\CalculatorPro  (أسعار الصرف، الإعدادات، سجل الأخطاء error.log)
معلومات المطور واسم البرنامج تُعدَّل من أعلى الملف (APP_NAME, DEVELOPER_NAME, WHATSAPP_NUMBER).
تنبيه: أسعار الصرف المعروضة مرجعية وليست عروض بيع وشراء لحظية؛ لذا يمكن تعديل وتثبيت أي سعر (مثل الريال اليمني).
مزوّد الأسعار ExchangeRate-API يشترط إظهار الرابط «Rates By Exchange Rate API» وهو موجود في تبويب المحولات.
